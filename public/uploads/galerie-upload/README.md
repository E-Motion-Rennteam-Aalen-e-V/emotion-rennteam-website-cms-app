Bilder, die hier abgelegt werden (.jpg, .jpeg, .png, .webp), erscheinen
automatisch in der Galerie – ohne dass dafür eine Markdown-Datei
angelegt werden muss. Der Titel wird aus dem Dateinamen erzeugt
(Bindestriche/Unterstriche werden zu Leerzeichen).

Einfach Dateien in diesen Ordner hochladen, committen und pushen.
